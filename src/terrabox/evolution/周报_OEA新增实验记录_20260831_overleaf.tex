\section{Weekly-Report Takeaways}

\begin{itemize}
    \item This week completed a strict no-label OEA reproduction of Memento-style CaseBank. The case bank uses only observable information from LongCat base rollouts and excludes task IDs, task types, expected tools, gold labels, metrics / F1, final answers, and exact task-fact leakage. All 1,162 OEA test tasks and the LongCat answer judge are complete.
    \item Strict Memento reaches set F1 0.705, multiset F1 0.647, success 87.0\%, ordinary answer accuracy 48.92\%, and generated-artifact-inclusive accuracy 72.54\%. Its generated-artifact metric is cleaner than the older Memento result, but it is still weaker than Ours.
    \item Ours remains the current main OEA result: set F1 0.774, multiset F1 0.722, success 92.5\%, and Answer+Gen accuracy 76.06\%. It also uses fewer tool calls and has a lower tool-error rate.
    \item Five full-set diagnostic experiments were added in late August: Ours plus final-answer verifier, no Quse/QNR, no step hint, no verifier, and random retrieval control. The largest degradation comes from removing the step hint, and random retrieval is weaker than matched retrieval, indicating that both retrieval quality and step-level artifact-state hints contribute to performance.
    \item The remaining unfinished items are MemRL external strict smoke / full, ExpeL strict smoke / full, and LongCat answer judging for the late-August ablations. These should continue under the strict no-label protocol; older results that include labels or expected tools should not be substituted.
\end{itemize}
