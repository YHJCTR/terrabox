## 当前主线

```text
OEA train2000 LongCat Base rollout
  -> rollout-derived v4-clean transition store
  -> OEA test read-only eval
  -> LongCat answer judge + 工具链/效率/经验使用指标
  -> matched Base + 因果对照 + 配对统计
```

ExperienceEvo 主线是 `rollout-derived offline self-evolution`。严格建库与 eval 不能使用 `task_type`、`expected_tools`、gold answer/tool calls、task id 或 F1 reward；gold 仅限事后评测、诊断和 teacher upper bound。

实验结果的论文使用分级、周报式总结和各结果目录见 `实验结果总览_20260725以来.md`。

## 维护规则

- 改动运行命令、store schema、GPU/服务配置、数据口径或指标口径时，同步更新相关 README 和 `AGENTS.md` / `CLAUDE.md`。
- 新正式实验先登记到当前实验计划，并记录 manifest、结果路径、状态与是否严格无标签。
- 未完成、异常期或混入口径的结果必须标记为诊断，不能写入主表。
- 不确定是否仍有价值的旧文档先归档到带日期的目录，避免直接删除可追溯信息。
