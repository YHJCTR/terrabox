## 当前主线

```text
OEA train2000 LongCat base rollout
  -> rollout-derived ExperienceEvo v2 store
  -> OEA test read-only eval
  -> 与 LongCat base / Reflection / MemRL 对比

OEA gold_tool_calls
  -> static audit
  -> teacher-forced replay smoke
  -> optional gold-replay store
  -> 只做 teacher upper-bound / 数据可执行性诊断

ExperienceEvo v4 ablation
  -> 固定 OEA test 覆盖子集
  -> default / checker_on / quse_off / step_hint_off
  -> rollout report + LongCat answer judge
  -> 判断收益来自多 agent checker、Quse 排序还是逐步检索
```

主方法仍然是 `rollout-derived offline self-evolution`。Gold 轨迹不能直接给 eval agent 看，也不能未经 replay 审计就蒸馏进主 store。
