## 1. 统一口径与边界

- 主数据集为 OEA test 全量 `1162` 条，做题模型均为 LongCat。除特别说明外，经验库均来自同一个 OEA train 覆盖子集 `2000` 条的实际 LongCat base rollout：`tmp/trajectories/longcat_oea_train2000_seed42_base_nightly_20260724/standard/results/`。
- `success` 只表示 agent 流程完成，不等于答案或工具轨迹正确；主结论不能只看 success。
- `answer_acc` 是 LongCat 对 `1020` 条普通答案任务的 judge 结果；`answer_acc_w_gen` 是 OEA 扩展口径，另计 `142` 条生成/展示任务的最后工具是否匹配且成功。二者均应与工具序列指标一起报告。
- 工具指标由 `terrabox.evolution.shared.rollout_report` 根据 `results/*.json` 重算。`set F1` 忽略重复调用，`multiset F1` 保留重复次数，`exact` 要求完整工具多重集合相同，`ordered exact` 还要求顺序相同，`LCS` 为顺序最长公共子序列比例。
- 部分旧结果目录有 `1162` 个 JSON，但报告有效记录数略少。答案判分仍按全体任务口径，工具指标以报告中的有效记录为准。因此不能把不同的历史 `report.json` 直接混为一个结论。
- 第三方方法必须保留复现边界。`official-source-guided`、`adapted/reimplemented` 和 `label-augmented` 不等于官方代码在 OEA 上的原样结果。
