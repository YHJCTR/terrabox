## 图6：完整 GRPO 训练日志

来源为 `qwen25_3b_swift_grpo_catalogprompt_obplaceholder_turn6_resp128_train2000_autofallback_20260912/checkpoints/swift/v4-20260913-152155/checkpoint-1900/trainer_state.json`，包含 step 1–1900。没有拼入 20260911 旧实验的负 reward 曲线。

浅蓝线为原始日志值，橙线为后向 25 步移动平均。面板依次为 reward、KL、turns、梯度范数、学习率、单步耗时、completion 截断比例、组内奖励标准差为零的比例。最后两项直接使用 Swift 日志字段，不能解释为任务失败率或工具错误率。未记录的 PPL、MFU 不补造；单步耗时也不冒充 tokens/s。

前100步与末100步的均值：reward 0.299→1.055，KL 0.00106→0.00355，turns 2.44→3.38，梯度范数 0.797→0.731，截断比例 67.25%→61.25%，组内奖励无差异比例 19.5%→6.0%。reward 有改善，但截断比例仍高，不能仅靠这条曲线宣称泛化或任务准确率提升。学习率曲线存在跳变，需要在实验设置中披露恢复过程；该图不证明优化器状态连续恢复。

ExperienceEvo 当前采用离线构建、测试时冻结的经验库，其 Q/N/R 来自历史事件统计，没有参数训练的逐步 loss，也没有 eval 中持续更新 Q/N/R 的学习曲线。图6属于独立 GRPO 训练；不能将经验库最终质量分布或按事件重放得到的统计曲线改名为 ExperienceEvo 训练收敛曲线。

英文图注建议：*Training diagnostics of the resumed Qwen2.5-3B GRPO run. Faint lines show logged values and orange lines show trailing 25-step averages. Learning-rate discontinuities are retained. These are training signals, not held-out task accuracy.*

## 图7–12：分布与运行诊断

- **图7**：按相同 task id 配对，绘制 ExperienceEvo−Base 的 Set F1 和工具调用数差值。F1 正值代表改善，调用数负值代表调用减少；调用减少不自动等于冗余减少。
- **图8**：按 task id 的数字后缀固定排序后累计 success。该顺序不是实际完成时间，曲线不是在线自进化曲线，也不能把上升解释成模型越测越聪明。建议只放补充材料。
- **图9**：按结果字段作互斥分类：success 为真优先；其次 status=failed；其次 has_tool_error；其余为未成功结果。不是经过人工审核的错误原因归因图。
- **图10**：success 与平均工具调用数的二维比较。不同历史方法存在环境/实现差异，只能作为描述性效率图，不证明严格意义的 Pareto 最优。
- **图11**：逐决策步的推荐覆盖、全决策分母的采纳比例和记录数。后期只有较长轨迹进入统计，存在幸存者选择；包括 final 决策，不能当作“在已有推荐条件下的采纳率”。step 0 的少量记录如实保留。
- **图12**：任务级 F1 和调用数的箱线图；中线为中位数、箱体为四分位范围、须线使用默认 1.5 IQR，保留离群点。

## 图13：推理过程中工具链如何展开

对每条真实轨迹只取前 k 次工具调用，k=0…20，离线重算工具集合 F1 和 expected-tool recall。已经停止的轨迹保持其最终工具序列，全体任务分母固定。因此曲线不会因为长链路任务留存而改变任务组成；它是保存轨迹的前缀分析，不是重新截断运行得到的任务成功率。重复调用在工具集合指标中去重。

图展示 LongCat 下 Base、ExperienceEvo、Reflection、MemRL、ExpeL、ACE。曲线用于分析更多调用是否增加覆盖、是否降低精确性；不能把工具命中等同于参数正确或最终答案正确。gold expected tools 只用于离线分析，不进入推理。

英文图注建议：*Tool-sequence quality as a function of the observed tool-call prefix. Each point averages over the same tasks; terminated trajectories retain their final sequence. Expected tools are used only for post-hoc scoring. Historical adapted baselines are shown descriptively and differ in execution configuration.*

## 图14：配对收益与不确定性

使用 matched Base 和 ExperienceEvo 的相同任务配对，按参考工具调用序列长度划分为 1–2、3–4、5+；分桶不是模型实际调用数，也不是严格的任务难度标签。每个分桶内对任务对进行 2000 次有放回 bootstrap（seed=42），显示均值及百分位 95% 区间；全部任务面板与分桶面板重叠，不视作独立证据。

全体任务的配对结果：

| 指标 | 均值差异 | 95% bootstrap 区间 |
|---|---:|---:|
| success | +5.68 个百分点 | [+3.61, +7.66] |
| Set F1 | +0.0706 | [+0.0578, +0.0844] |
| 每任务调用减少 | 1.677 | [1.483, 1.875] |

5+ 链长组的 F1 增益区间跨零，因此不能宣称对所有链长都有稳定 F1 提升。区间只反映当前测试任务抽样不确定性，不覆盖训练种子、模型随机性或环境变动。

英文图注建议：*Paired differences between ExperienceEvo and its matched Base, stratified by reference tool-chain length. Error bars are percentile 95% intervals from 2,000 task-paired bootstrap resamples. Positive values indicate higher recorded success, higher Set F1, or fewer tool calls, respectively.*

## 结果口径与复现

所有 LongCat 方法都有相同的 1162 个 task id，已自动检查数量、success 均值、F1 均值与各自 report 一致。matched Base/ExperienceEvo 额外检查问题文本、expected tools 和 allowed slugs 一致；这不能取代全部运行配置的可比性审计。success 使用结果文件的原始 success 字段，不是独立答案 judge 准确率。

MemRL 是 label-augmented adapted 对照；其余历史复现的实现边界和服务配置需要在论文中沿用各实验说明。不能仅凭本组图宣称所有方法在完全相同环境下公平比较或无条件 SOTA。

数据表保存于 `figures_v2/`：`training_metrics.csv`、`all_task_metrics.csv`、`paired_task_deltas.csv`、`paired_bootstrap.csv`、`inference_prefix_metrics.csv`、`decision_step_counts.csv`。路径、核验值和首末训练统计保存在 `图表说明_v2.json`。

用户已允许脚本生成图表，本次保留复现入口 `reproduce_figures.py`。绘图依赖安装在仓库 `tmp/plotenv`，没有修改训练环境；原始结果不改写。仓库根目录运行：
